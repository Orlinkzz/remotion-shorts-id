Mulai dalam 4 langkah

Butuh Node.js 20.19+, 22.13+, atau 24+. Transkripsi pertama kali mengunduh Whisper.cpp dan model small (±466 MB).

  1. Pasang proyek

    git clone https://github.com/Orlinkzz/remotion-shorts-id.git
cd remotion-shorts-id
npm install

  2. Tulis naskah

    Buat public/videos/<id>/video.json. Setiap scene wajib punya narration, yaitu kalimat yang diucapkan di scene itu.

    public/videos/n-plus-one/video.json
    {
  "$schema": "../../../video.schema.json",
  "title": "3 tips anti N+1 query di Laravel",
  "voice": "voice.mp3",
  "scenes": [
    {
      "type": "hook",
      "narration": "Hati-hati, N+1 query bisa bikin API Laravel kamu lambat banget.",
      "speech": "Hati-hati, N plus one query bisa bikin API Laravel kamu lambat banget.",
      "text": "*N+1 query* bikin API-mu lambat"
    },
    {
      "type": "code",
      "narration": "Solusinya pakai eager loading dengan method with.",
      "language": "php",
      "filename": "PostController.php",
      "code": "$posts = Post::with('author')->get();",
      "highlightLines": [[1, 1]]
    },
    {
      "type": "outro",
      "narration": "Follow untuk tips Laravel berikutnya.",
      "cta": "Follow untuk tips backend lainnya"
    }
  ]
}

  3. Buat suara

    Pilih TTS (tanpa rekaman) atau rekaman sendiri. Keduanya menghasilkan captions.json untuk sinkronisasi.

    npm run validate n-plus-one
npm run tts n-plus-one          # TTS: voice.mp3 + captions.json
# atau rekaman sendiri di public/videos/n-plus-one/voice.mp3:
npm run transcribe n-plus-one

  4. Cek lalu render

    Buka Remotion Studio untuk pratinjau, lalu render ke MP4.

    npm run dev                     # Studio, composition "Short"
npm run render n-plus-one       # hasil: out/n-plus-one.mp4

TTS tanpa rekaman

npm run tts <id> mencoba provider berurutan. Kalau satu gagal karena limit, jaringan, atau key kosong, seluruh video dibuat ulang dengan provider berikutnya supaya suaranya tetap satu orang.

UrutanProviderKeterangan
1edgegratisSuara neural Microsoft (mis. id-ID-ArdiNeural) lewat layanan Read Aloud Edge. Tanpa key, tidak resmi.
2azurekeyAzure Speech resmi, kuota gratis bulanan. Isi AZURE_SPEECH_KEY dan AZURE_SPEECH_REGION di .env.
3googlekeyGoogle Cloud Text-to-Speech resmi, kuota gratis bulanan. Isi GOOGLE_TTS_API_KEY di .env.
4gtranslategratisCadangan terakhir tanpa key, suara robotik.
Opsi
npm run tts <id> -- --provider=google   # paksa satu provider
npm run tts <id> -- --no-transcribe     # hanya audio
npm run tts <id> -- --force             # timpa rekaman

Pelafalan dan cache

Isi speech di scene kalau yang diucapkan harus beda dari caption, mis. "N+1" dibaca "N plus one". Audio per scene di-cache, jadi yang dibuat ulang hanya scene yang teksnya berubah. Suara, kecepatan, dan jeda diatur di tts-config.mjs.

Tipe scene

Semua scene wajib punya narration dan boleh punya speech. Tulis *kata* untuk memberi warna aksen.

Cara sinkronisasi bekerja

Kata di naskah dicocokkan dengan kata hasil Whisper memakai alignment urutan dan pencocokan fuzzy. Kata yang tidak terdeteksi diinterpolasi dari tetangganya. Scene mulai 120 ms sebelum kata pertamanya diucapkan, dan durasi video sama dengan panjang audio ditambah jeda akhir.

Background memakai komponen NotebookPaper (grid, cahaya, grain) yang bisa diatur dari panel Props di Studio, termasuk preset warna indigo, emerald, rose, dan amber.

Struktur
src/
  compositions/   Short.tsx, background NotebookPaper
  scenes/         Hook, Code, Points, Outro

Pertanyaan umum

Apakah harus merekam suara sendiri?

Tidak. Jalankan npm run tts <id> untuk membuat suara dari naskah. Rekaman sendiri tetap bisa dipakai lewat npm run transcribe <id>, dan npm run tts tidak akan menimpa rekaman tanpa -- --force.

Apakah gratis untuk konten komersial?

Kode proyek ini MIT. Remotion gratis untuk individu, perusahaan dengan maksimal 3 karyawan, dan nirlaba; perusahaan yang lebih besar butuh Company License. Untuk audio komersial, pakai provider resmi (Azure atau Google) atau rekaman sendiri.

Kenapa ejaan istilah teknis di caption selalu benar?

Caption diambil dari naskah. Whisper hanya memberi timestamp, jadi salah dengar istilah Inggris tidak pernah muncul di layar.

Bagaimana kalau layanan TTS kena limit?

Provider dicoba berurutan: edge, azure, google, gtranslate. Azure dan Google otomatis dilewati kalau key belum diisi.

Bisa dipakai bersama AI agent?

Bisa. AGENTS.md berisi petunjuk untuk agent di VS Code (Claude Code, Copilot, dan lainnya). Agent cukup menulis video.json dan menjalankan perintah npm.
